# 사이트 설계도(PRD) — 로또 번호 추출기 (가칭)

작성일: 2026-10-15 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
지난 로또 당첨 기록 통계를 참고하고, 실제 추첨처럼 공을 굴려 번호를 뽑아 주는 사이트.

> 주의: 로또는 매 회차 무작위라서 어떤 방법으로도 당첨 확률이 올라가지 않는다.
> 사이트에 "당첨 확률이 높은", "당첨 보장" 같은 말은 쓰지 않는다. "통계 참고용 · 재미로" 라고 쓴다.

## 2. 손님
- 누가: 통계 좋아하는 사람 (자주 나온 번호·안 나온 번호를 따져 보고 고르는 사람)
- 어디서 알고 오나: 로또 커뮤니티·카페에 공유된 링크

## 3. 손님이 궁금한 것 (뽑기 전에)
1. 자주 나온 번호 (그리고 안 나온 번호)
2. 어떤 방식으로 뽑나 (통계를 어떻게 쓰는지, 공 굴리기는 어떻게 하는지)
3. 최근 당첨 번호

## 4. 믿게 할 증거 (실제로 있는 것만)
- 공식 당첨 기록 출처: 통계는 동행복권(dhlottery.co.kr)의 실제 지난 당첨 번호로 계산했다고 밝히고, 몇 회차까지 반영했는지 날짜와 함께 보여 준다
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 번호 뽑기
- 누르면: 공이 굴러가며 번호가 하나씩 나온다 (문의 폼 아님)

## 6. 페이지 구성 (위에서 아래로, 한 장)
1. 첫 화면 — 한 문장 + 줄 수 고르기(1~5줄) + [번호 뽑기] 버튼
2. 뽑기 결과 — 공 굴리기 연출, 뽑힌 번호 줄, [내 번호 저장]
3. 최근 당첨 번호 — 가장 최근 회차 번호 + 보너스 번호
4. 번호 통계 — 1~45 각 번호가 나온 횟수 그래프, 자주 나온 번호 · 오래 안 나온 번호
5. 어떻게 뽑나요? — 뽑는 방법을 쉬운 말로 설명 + 데이터 출처 + "당첨을 보장하지 않아요" 안내
6. 내가 저장한 번호 — 이 기기(브라우저)에 저장한 번호 목록, 최근 당첨 번호와 맞춰 보기
7. 후기 자리 (비워 둠)

## 7. 문의 폼에서 받을 것
- 이번에는 문의 폼 없음 (11번 "다음에 할 것"으로)

## 8. 정확해야 하는 사실
- 번호: 1~45 중 6개 + 보너스 번호 1개 (한국 로또 6/45)
- 한 번에 뽑는 수: 손님이 1~5줄 중 고른다
- 데이터 출처: 동행복권 공식 지난 당첨 번호 · 반영한 마지막 회차와 날짜를 꼭 표시
- 가격: 무료 (가입 없음)
- 연락 방법: (미정 — 이번에는 넣지 않음)

## 9. 이번에 넣지 않을 것
- 결제·유료 번호
- 번호 공유 버튼 (카톡·카페로 보내기)
- 문의 저장 · 관리자 페이지(/admin)
- 회원가입·로그인 (저장한 번호는 손님 브라우저에만 남는다)

## 10. 첫 화면 한 문장 후보
1. 지난 당첨 기록을 보고, 추첨처럼 굴려서 뽑아요.
2. 숫자로 보는 로또 — 통계를 참고해 번호 6개를 뽑아 보세요.
3. 자주 나온 번호, 오래 쉰 번호. 보고 고르고, 굴려서 뽑기.

## 11. 다음에 할 것
- 번호 공유 버튼 (카톡·카페)
- 의견·문의 폼 (필요해지면 Supabase + /admin)
- 회원가입하고 어느 기기에서나 내 번호 보기 (이때 개인정보 처리방침 필요)
- 결제·유료 기능 (하게 되면 과장 광고가 되지 않게 다시 검토)
- 실제 후기 모으기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 (표·그래프가 잘 보이는 데이터 화면) · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 아니오
- 관리자 페이지: 없음 — 새 당첨 번호는 공개 기록에서 매주 자동으로 가져온다 (가져오는 방법은 만들 때 확인하고, 안 되면 사용자에게 알린다)
- 회원가입: 이번엔 아니요 — 저장한 번호는 브라우저 저장소(localStorage)에
- 위치: C:\MYSITE\lotto (절 사이트와 따로)
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면(번호 뽑기)부터 만든다
2. 지난 당첨 번호 데이터를 넣고 통계·최근 당첨 번호 칸을 만든다
3. 새 당첨 번호를 매주 자동으로 가져오게 한다
4. 내 번호 저장(브라우저)과 당첨 맞춰 보기를 만든다
5. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
6. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제
